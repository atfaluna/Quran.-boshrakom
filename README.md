# Quran.-boshrakom
## جمعية بشراكم لتحفيظ القرآن — نظام متابعة الطلاب

نسخة أولية لتطبيق ويب عربي متجاوب لإدارة:
- الطلاب والحلقات والمعلمين
- الحضور والغياب
- الحفظ الجديد والمراجعة
- تقييم الحفظ والتجويد والأخطاء
- التقارير والإحصائيات
- **مصحف داخل حساب كل معلم** لربط موضع التلاوة مباشرة بسجل الطالب

### مهم
هذه النسخة لا تحتوي على بيانات طلاب حقيقية ولا مفاتيح سرية.
نص المصحف الكامل سيُربط لاحقًا بمصدر قرآني موثوق ومراجع، مع الحفاظ على الرسم العثماني.

### التشغيل
افتح `index.html` مباشرة في المتصفح، أو انشر المشروع على Vercel / GitHub Pages.
